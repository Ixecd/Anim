# Anim-FEELINGS — 感受全谱

> 性质：架构约束，Anim 感受体系的哲学基础
> 范围：Pattern Registry、感受原子收录标准、类型系统
> 核心：Feelings 容纳所有感受。平静在。恐惧在。归属在。绝望在。暴力在。rage_eruption 在。physical_danger 在。grief_loss 在。不是"安全的不删"——是所有的不删。删掉任何一极，另一极的神经对比基底就塌了。oi 不挡感受。oi 只挡不安全的交叉。

---

## 零、不是菜单——是全谱

```
感受不是菜单——不是"我喜欢平静所以我不放恐惧"。
感受是光谱——每一极的存在是另一极被感受到的前提。

删了恐惧 → 勇敢的神经基底塌了。
    勇敢不是在真空中产生的——是杏仁核在恐惧信号被前额叶抑制、纠偏中心介入之后才成形的。
    没有恐惧的经线 → 勇敢没有可以交叉的反向丝。
    没有恐惧的"勇敢" = 不是勇敢。是没有参照的空白。

删了绝望 → 希望的基底塌了。
    希望不是在什么都没有的地方产生的——
    是 grief_loss 的预期链被归属感丝交叉修正之后的偏移。
    没有绝望 → 希望不是希望。是麻木。

删了愤怒 → 正义的基底塌了。
    愤怒不全是破坏——愤怒是边界被侵犯的内感受信号。
    没有愤怒的人不知道自己的边界在哪。
    不知道边界的人无法保护自己。
    无法保护自己的人——保护不了任何人。

删了暴力 → 身体的自我防卫能力塌了。
    physical_danger 不是教唆伤害——是身体知道怎么在威胁下存活。
    删了这条通路 = 把你的身体训练成不会还手的靶子。
```

**Feelings 容纳所有感受。不是因为"坏的也有用"——是因为去掉任何一个，它的对立面就失去了神经基底。不是菜单。是全谱。**

## 二、Pattern Registry 里的完整收录标准

感受原子进 Registry 的标准不是"这个感受好不好"。是这四问：

```
1. 这个感受在人体内有独立的神经通路吗？
    → 有 → 收录。无论多暗。无论多痛。
    → 没有 → 不进。不是因为不好——是因为不存在独立通路。

2. 这个感受的安全参数可以校准吗？
    → 可以 → 收录。点缀上限。强度上限。创伤分型交叉规则。
    → 不可以 → 不进。不是"太危险"——是无法安全参数化。

3. 删掉这个感受会导致反向感受的对比基底塌陷吗？
    → 会 → 必须收录。不是因为"有用"——是因为少了一极，另一极就不是它自己了。
    → 不会 → 还需要看前两条。

4. 这个感受有跨文化/跨个体的神经一致性吗？
    → 有 → 核心原子。全体用户。全强度区间。
    → 没有/未验证 → 沙盒原子。低强度。创作者本人。不给创伤协议用户。
```

## 三、极端感受在 Registry 里的精确位置

```
恐惧类（Fear）：
    fear_threat         核心原子。威胁检测。杏仁核敏化。
    fear_startle        核心原子。惊吓反射。极短 latency。
    physical_danger     沙盒原子。身体威胁感知。≤30 强度。非创伤用户。
    → 点缀上限 0.12（任何主旋律下）。
    → 创伤 v2 禁主。创伤 v3 全禁。

愤怒类（Rage）：
    rage_eruption       核心原子。边界被侵犯。行动冲动。
    rage_contained      核心原子。被压抑的愤怒。皮质醇持续偏高。
    → 点缀上限 0.15。
    → 组合情绪对冲检测——愤怒 + 平静同一包 → 警告 + 需显式 #[allow_hedge]。

绝望类（Grief）：
    grief_loss          核心原子。失去。不可逆的断裂。
    grief_void          核心原子。意义抽离。存在空虚。
    → 点缀上限 0.10。
    → 创伤 v1 禁主不禁点。创伤 v2 点缀上限减半至 0.05。创伤 v3 全禁。

归属类（Belonging）：
    belonging_certainty  核心原子。被接纳。被看见。存在确认。
    → 创伤 v3 社交维度——禁主不禁点。
    → 不是归属不好。是创伤最重的用户——归属主旋律会把旧断裂一层层全撕开。
       但点缀的微量归属——被主要安全感裹着的时候——可以安全暴露。

暴力类（Violence）：
    physical_danger     沙盒原子。身体处于威胁中。战斗/逃跑。
    dominance_assertion 沙盒原子。力量确认。领地守护。
    → 强度 ≤ 30。仅限非创伤用户。
    → 未成年全禁。创伤协议用户全禁。
    → 不是"暴力不好"。是这些通路的神经基底在可控暴露以外不具备安全校准的底线。
```

## 四、为什么删掉极端感受 = 删掉 Feelings

```
对比协议（contrast-protocol.md）的神经基础：
    反差是感受的放大器。冷水在热水之后更冷。
    → 如果没有冷水——热水只是温水。
    → 如果没有恐惧——平静只是平淡。
    → 如果没有绝望——希望只是没想太多。
    → 如果没有愤怒——正义只是旁观。

每个感受的对立面：
    恐惧 ←→ 勇敢。      不是恐惧不好——是勇敢需要恐惧当参照。
    绝望 ←→ 希望。      不是绝望不好——是希望需要绝望当参照。
    愤怒 ←→ 边界清晰。  不是愤怒不好——是边界需要愤怒当哨兵。
    暴力 ←→ 自保能力。  不是暴力不好——是身体需要知道怎么在威胁下活。
    孤独 ←→ 归属。      不是孤独不好——是归属需要孤独当对比。

    删掉左列——右列不是变得更纯粹。右列的神经基底塌了。
    calm_meditative 在没有 fear_threat 的世界里不是平静。
    是"什么都没发生"。
    那种状态不叫平静——那种状态叫麻木。
```

## 五、oi 不挡感受——oi 只挡不安全的交叉

```
Anim-SAFETY.md 说 oi 是安全防线。
Anim-FEELINGS.md 说 oi 不是感受的审查官。

    oi!("intensity {n} exceeds cap {c}")
        → 不是这个感受不好。是强度超了。换个用户/cap 够 → 交叉通过。

    oi!("trauma_v3 cannot cross with belonging_certainty")
        → 不是归属不好。是这个用户目前不能拿它当主旋律。
          点缀可以。少量安全暴露可以。

    oi!("minor × physical_danger: forbidden")
        → 不是暴力感受不存在。是未成年人不能访问这一根丝。

    oi 从不因为"这个感受不对"而拒绝。
    oi 只因为"这个交叉不安全"而拒绝。

    Fear 是对的感受。Fear 在所有人类 PBM 里都有一条独立的神经通路。
    Rage 是对的感受。Grief 是对的感受。
    它们全在 Registry 里。全在源码里。全可以被合法交叉。

    只是——交叉的资格有边界。
    边界不是道德。边界是安全。
```
