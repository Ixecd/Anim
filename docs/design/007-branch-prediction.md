# ADR 007: 分支预测——从 Smith 1981 到 Anim 帧级预判

> 状态：定稿
> 日期：2026-05-29
> 性质：Anim 预测器设计的硬件理论基础
> 来源：Smith 1981 "A Study of Branch Prediction Strategies" 及后续四十年分支预测研究的逐层推演
> 核心：Smith 的 2-bit 饱和计数器不只改变了 CPU 设计——它定义了 Anim 的 PBM 冷启动逻辑、帧级预判的置信度更新、以及"预测失败不 panic——安全插桩接管"的硬件哲学。

---

## 零、Anim 预测器不是凭空设计——它继承了四十年的分支预测研究

Anim 的帧级预判器——ADR 004 里那句"预测器跑在 FPGA 上，查寄存器 + 简单线性外推"——背后是一整套 CPU 分支预测的演化史。从 Smith 1981 的 2-bit 饱和计数器，到 Yeh & Patt 1991 的两层自适应，到 McFarling 1993 的组合预测器，到 Jiménez 2001 的感知器，到 Seznec 2016 的 TAGE-SC-L。

Anim 不需要其中最复杂的部分——因为生理信号预测的精度天花板比 CPU 分支预测低得多（人体是非平稳随机过程，CPU 是确定性程序）。但 Anim 需要其中最核心的**哲学**——如何从历史中学习，如何在预测错误时不崩溃，如何让两个弱模型加起来比一个强模型更可靠。

---

## 一、Smith 之前——没有预测，只有等待

CPU 执行一条分支指令（`if`、`for`、`while`）。在计算结果出来之前——CPU 不知道下一条指令在哪。最原始的 CPU 选择**停**。停下取指。等 ALU 算完条件码。然后从正确的地址继续。程序大约 20% 的指令是分支。意味着 CPU 有 20% 的时间在等待。流水线空转。晶体管漏电。

后来有人试了**静态预测**——编译器在生成代码时给每个分支贴标签。向后跳的（循环底部）→ 猜跳。向前跳的（if-else 分支）→ 猜不跳。正确率大约 60-70%。比瞎猜 50% 好。但错了之后——冲刷流水线，把所有错误路径上取的指令全部扔掉。从 70% 提升到 90% 以上——收益巨大。

---

## 二、Smith 1981 —— 让分支自己记住自己

Smith 的核心想法简单到令人惊讶：**每个分支指令的地址被哈希到一个 2-bit 计数器。计数器记录这个分支最近的行为模式。**

```
00 = 强不跳     "我两次没跳。我不跳。我很确定。"
01 = 弱不跳     "我上次跳了。但就那一次。我还不信。"
10 = 弱跳       "我上次没跳了。但就那一次。我再看看。"
11 = 强跳       "我跳了两次。我跳。我很确定。"
```

分支执行完。实际结果是"跳了"→ 计数器 +1（但不超 11）。实际结果"没跳"→ 计数器 -1（但不低于 00）。

这就是**饱和计数器**——不会从"强不跳"因为一次异常就跳到"强跳"。永远是慢慢地偏过去。在几十次、几百次执行中自己校准。这不是"记住上一次"。这是**从整个历史中提取方向**。一次意外不会推翻长期形成的模式。

正确率——**93% 到 98%。** 一个 2 bit 的计数器，比编译器精心设计的静态分析准了二十多个百分点。不是算法更聪明。是它不假设任何事。它让每个分支从自己的历史里学。

## 三、Smith 论文里没有被充分展开的洞察——两个弱预测器 > 一个强预测器

Smith 在论文的后半段试了一种方案。先用一个简单的计数器做初判。再用一个更复杂的模式匹配器做精判。两者不一致时，信后者。两者一致时，加速响应。

这个洞察在 1981 年没有被充分论证。但十二年后——McFarling 1993 发表了《Combining Branch Predictors》，把"两个弱预测器组合"变成了现代 CPU 的标准架构。再后来——Seznec 2016 的 TAGE-SC-L 用**多个**不同历史长度的预测表 + 统计校正器，在 Championship Branch Prediction 上拿了冠军。Smith 1981 的 2-bit 计数器——是这一切的起点。

## 四、Anim 从 Smith 学到了三件事

### 4.1 PBM 的冷启动——2-bit 饱和计数器的感受版本

PBM 的四维差异化冷启动系数（内脏 0.75 / 情绪 0.40 / 触觉 0.80 / 听觉 0.85）不是固定乘子。它是一个**饱和计数器的初始化状态**。

```
Smith 计数器                      PBM 冷启动
────────────                      ──────────
初始值 01（弱不跳）                初始值 0.40（情绪维度——最保守）
每次执行结果 → +1 或 -1           每次 session 生理反馈 → 微调
方向从不跳偏到跳                  方向从人群均值→个人真实基线
偏的过程是饱和的——不会跳变        微调有上下限锁——不会溢出
几十次执行后稳定在真实方向         几十次 session 后 PBM 收敛
```

PBM 不是"被测量"的——是**被分支预测逻辑从历史中提取出来的**。和 Smith 计数器完全同构——不是信一次。是信足够多次之后，偏移自己到达稳定。到那时——不再需要外部信号维持。预测已经焊在身体里了。

### 4.2 帧级预判——"分支"在 Anim 里不是 if/else，是生理状态的分岔

```
CPU 分支预测                    Anim 帧级预判
────────────                   ─────────────
分支 = 下一条指令走哪条路        分支 = 下一帧生理响应往哪偏
预测器 = 2-bit 饱和计数器        预测器 = 用户历史生理曲线 + 当前趋势
预测对 → 流水线无缝继续          预判对 → ESIR 帧零延迟衔接
预测错 → 冲刷流水线，重取指令    预判错 → 安全插桩接管，切回保守帧
```

Anim 的"分支"不在 `.anim` 源码里——在人体神经系统的实时状态里。心率超标 vs 心率平稳 → 两条不同的 ESIR 修正路径。皮电骤升 vs 皮电平稳 → 两条不同的 shape 保持/暂停路径。三种信号同时异常 → 唯一路径——保底包激活。

每一帧都是一次分支决策。Smith 的 2-bit 计数器不能直接用——生理信号不是确定性的——但**饱和更新**的逻辑完全保留。每一帧看完生理反馈之后，往"准"的方向微调。不多。饱和的。慢的。

### 4.3 预测错误不 panic——安全插桩接管

CPU 分支预测错了——冲刷流水线，浪费几十个时钟周期。然后从正确地址继续。代价是时间。不是安全。

Anim 的分支预测错了——信号已经进了人体。不能"冲刷流水线"。不能"浪费几十个时钟周期"。代价不是时间——是**一次真实的生理响应**。

所以 Anim 的做法和 Smith 有一个根本性差异。Smith 的计数器在预测错误后继续用同一个计数器——只是减一。Anim 不能。Anim 在预测错误时**不继续**——安全插桩立刻接管。不是"等下一帧"。是这一帧就切回保底包。不是"重新预测"。是**暂时的——放弃预测——用最保守的信号填补这一帧**。然后从当前真实状态重新校准。

这和 Smith 的饱和计数器在哲学上同源，在实现上更激进——**预测的代价不允许多次错误。但学习逻辑不变——微调。饱和。慢慢偏。直到稳定。**

## 五、Anim 不需要 TAGE——但需要知道为什么不需要

Seznec 2016 的 TAGE-SC-L 用了多个不同历史长度的预测表。最长的一根表记录了超过 2000 次历史分支的模式。正确率超过 99%。代价——巨大的片上 SRAM 和复杂的统计校正逻辑。

Anim 不需要这个精度——因为生理信号的**可预测性上限**远低于 CPU 程序。CPU 的分支来自确定性算法——同一个输入永远产生同一个输出。人体的生理响应来自非平稳随机过程——同一个信号，今天和昨天的响应可能因为咖啡因、睡眠、情绪状态而完全不同。

Anim 不需要 99% 的预测准确率。Anim 需要的是**"预测错了之后不伤人"**。这个保证不来自更复杂的预测器——来自安全插桩。来自 Emergency Bypass 硬件衰减状态机。来自"预测器猜错了——安全层兜底"这个架构。

**Smith 教 Anim 怎么从历史中学。TAGE 教 Anim 不要追求完美预测——因为人体不是程序。**
